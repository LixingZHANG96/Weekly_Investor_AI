# Weekly_Investor_AI
With this project, I intend to create myself a project, which give out investment suggestions on a weekly base. 

# Structure of the Project
## Part 1. Data Input
1. A Database for my portfolio management, this should be kept inside a .yaml file
2. Weekly Market Data
3. News and Reports
## Part 2. Data Analysis
1. A Quant Engine would be used to generate invest strategies
2. An reasonging LLM to reason out the strategies
## Part 3. AI Agents for decisions
1. Macro Analyst: He is responsible for macro data, like interest, inflation rates, GDP, unemployment statics and so on.
2. Equity Analyst: He would take a step further and view things like Financial Reports, valuations.
3. Quant Analyst: He focuses on numerical data like: Momentum, valuation, volatility etc.
4. (extra) Risk Manager: Questions the decisions made from the former 3 agents.
5. Investment Committee: Concludes everything and output for the final report.
## Part 4. Weekly Report: This should concludes everything and report them in a formatted way.
## (Add-on) Challenge Mode
The system should also allow me to throw quesions and defend their decisions
